Out-of-distribution test — held-out species

The augmenter (trained on grayscale brightfield P. aeruginosa branching colonies) run on a two-species fluorescence co-culture (KL set) it never saw. This is the "does it generalize to a novel species?" test.

Result: it does not generalize. On every novel input — a solid red colony, a green+red co-culture, even a near-empty plate — the model generates the same grayscale dendritic sunburst. It strips the fluorescence, ignores the input's shape, and imposes its training-domain branching prior. Diversity is unchanged, so it is not mode-collapsing — it is confidently generating the wrong thing.

Reading it

In-domain is genuinely good: realism (0.314) is only 1.36× the real-vs-real baseline (0.232) and diversity is healthy — the model makes replicate-quality images and doesn't mode-collapse.

OOD confirms the open problem: a novel species blows up FID 4.7× and pushes realism to 2.26× the baseline. The mechanism (see images): ControlNet conditioning fails OOD — the model leans on its learned prior instead of the input.

Caveat: KL shifts species + imaging modality (fluorescence) + morphology all at once, so this shows that it breaks on a genuinely novel input, not which single factor causes it. A brightfield-but-different-species set would isolate the species variable.
